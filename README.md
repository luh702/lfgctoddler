# 런던순복음교회 유아부 주일 출석체크 (v1.8)

유아부 반별 주일 출석체크 웹앱 — 시범용 프로토타입입니다.

- 단일 HTML 파일(`index.html`), 바닐라 HTML/CSS/JS
- **v1.0부터 Supabase 실시간 공유 DB를 씁니다.** 한 기기(폰)에서 출석을 찍으면 다른 기기에도 몇 초 안에 그대로 보입니다.
- 반별 입장(잠금을 켜면 4자리 PIN) / 관리자(임원·교역자) 통합 PIN `1004`
- **v1.6 관리 탭에서 직접 바꾸기** — 개발 수정을 기다리지 않고 관리자 PIN으로 들어가서 바로 고칩니다. 모두 `app_state`의 `meta` 한 줄에 저장돼 모든 선생님 기기에 몇 초 안에 반영됩니다.
  - **반 추가** `+ 반 추가` (반 이름·한 줄 소개), **순서** `▲` `▼`, **반 삭제** `🗑`. 반이 5개로 고정되어 있지 않고 원하는 만큼 만들 수 있어요. 반이 하나뿐일 때는 지울 수 없고, 지울 반에 아이·선생님이 남아 있으면 **옮길 반을 골라 옮긴 뒤** 지웁니다(출석·기도 기록은 아이를 따라 그대로 이동).
  - **부서·앱 제목** (기본 `런던순복음교회 유아부`) — 머리글과 로그인 화면 제목에 바로 반영.
  - **교사 한 줄 공지** — 적으면 출석 화면 맨 위에 한 줄 배너로 뜨고, 비우면 배너가 사라져요.
  - **졸업 기준 월·나이** (기본 9월 · 만 5세) — 바꾸면 모든 아이의 졸업예정일이 즉시 다시 계산됩니다(직접 지정한 아이는 그대로).
- **v1.8 🗑 명단 정리는 관리 탭에서** — 원아 일괄 선택·삭제를 **출석 탭에서 관리 탭으로 옮겼습니다**(출석 화면은 매주 출석 체크만 남겨 깔끔하게). 관리 탭 맨 아래 `명단 정리` 카드에서 **반 필터(전체 / 반별)** 로 좁히고, 아이를 눌러 체크한 뒤(`전체 선택`/`전체 해제`, `선택 N명` 표시) `🗑 선택 삭제`를 누르면 **몇 명을 지우는지 이름과 함께 확인 창**이 뜹니다. 확인하면 그 아이들의 출석·메모·기도제목 기록까지 함께 정리해 서버(`children`·`att:*`·`prayer:*`)에 바로 저장되고 모든 기기에 반영됩니다(관리자만 보입니다). 명단 정리 목록은 입교일과 상관없이 그 반 아이를 모두 보여 줘서, 오래된 아이도 지울 수 있어요.
- **v1.8 🎓 졸업 예정일 계산을 바로잡음** — 기준을 글자 그대로 `만 N세가 된 뒤 처음 오는 기준 월 1일`로 계산합니다(예: 2021년 10월생 · 만 5세 · 9월 → 2027.09.01). 이미 지난 학기(예: 2026년 9월)가 `졸업 예정/대상`으로 뜨지 않고, 지난 날짜면 **다가오는 다음 학기(2027년 9월)** 로 넘겨 보여 줍니다. 직접 지정한 졸업일이 지난 아이는 `🎓 지난 졸업`으로 표시하고 `지난 졸업 N명 보기`에 모읍니다(옛 표기 `졸업 대상`은 없앴습니다).
- **v1.7 🎂 선생님 생일** — 관리 탭에서 선생님 줄을 누르면 **생일(월·일)**을 넣을 수 있습니다(출생연도는 받지 않아요 — 선생님이 부담 없이 넣을 수 있게). 명단 줄에 `🎂 3/14`처럼 보이고, 관리 탭 맨 위 `🎂 이번 달 선생님 생일` 카드 · 출석 화면 `🎉 이번 달 선생님 생일 N명` 스트립 · 생일 탭 `🎉 이달의 선생님 생일`에서 이번 달 생일을 모아 봅니다(오늘은 `오늘 🎉`, 다가오면 `D-n`).
- 반은 나이대가 아니라 이름으로만 구분합니다. **v1.5부터 반 한 줄 소개는 기본으로 비어 있어** 반 이름 옆에 설명이 뜨지 않아요. 관리 탭 > 반 정보 수정에서 원할 때만 넣을 수 있습니다(서버 `classes`의 `desc`도 모두 빈 값).
- 반 카드를 눌러 입장할 때 확인 창은 **`👩‍🏫 담당 선생님` 라벨이 먼저, 그 아래에 선생님 이름** 순서로 보여 줍니다.
- 관리자 모드는 아이·선생님을 손잡이(⠿)로 **끌어서 다른 반으로 이동**할 수 있습니다. **v1.5에서 손가락(안드로이드 크롬·iOS 사파리) 드래그를 다시 손봤어요.**
  - 손잡이를 44×44로 키우고 `touch-action:none`·`user-select:none`·`-webkit-touch-callout:none`을 걸어 스크롤·텍스트 선택·길게 누르기 미리보기에 먹히지 않습니다.
  - 마우스·펜은 Pointer Events, 손가락은 Touch Events(`touchmove`는 `{ passive:false }` + `preventDefault`)로 **한 경로만** 타서 한 동작이 두 번 처리되지 않습니다.
  - 끌면 화면 아래에 **'놓을 반' 칩 바**가 떠서, 반 카드까지 스크롤하지 않고도 손가락으로 정확히 놓을 수 있습니다. 가장자리에서는 자동 스크롤됩니다.
  - 관리 탭의 선생님·아이 줄은 **줄 자체를 눌러도 수정 창**이 열립니다(수정·삭제 버튼도 36px 높이로 키움). 반 선택(셀렉트)·수정 창은 그대로 보조 수단으로 남아 있어요.
- **v1.5 🎓 졸업 예정자 모아보기** — 출석 화면에 `🎓 졸업 예정자 N명` 카드가 떠서 1년 안에 졸업하는 아이를 반·이름·생년월일·졸업예정일·D-day와 함께 한곳에 보여 줍니다. 줄을 누르면 그 아이 정보 창이 열리고, `지난 졸업 대상 N명 보기`로 이미 지난 아이까지 펼쳐 볼 수 있어요. 대상자가 없으면 카드가 나타나지 않습니다.
- **v1.3 졸업 예정(v1.3)** — 아이의 생년월일을 넣거나 바꾸면 영국 9월 학기(만 5세) 기준으로 **졸업 예정일과 D-day가 자동 계산**됩니다. 등록·수정 창에서 `자동 계산 / 직접 지정`을 골라 날짜를 직접 지정할 수 있고, `↺ 자동 계산으로 돌아가기`를 누르면 생일 기준으로 돌아갑니다(직접 지정한 값은 `graduation` 필드, 없으면 자동).
- **v1.3 새친구반 원탭 반 배정** — 새친구반 카드 아래 `🐣 반 배정` 줄에서 **믿음·소망·사랑·은혜반 이름을 한 번 누르면** 확인 후 바로 그 반으로 배정되고 Supabase `children` 행에 즉시 저장됩니다. 권한은 기존 규칙 그대로 **관리자(임원)와 새친구반 담당 선생님만**(타 반 읽기 전용 방문자에게는 버튼이 보이지 않음).
- 서버에 연결하지 못하면(지하·비행기 등) 이 기기(`localStorage`)에 먼저 저장하고, 연결되면 자동으로 다시 올립니다.
- **v1.4 📷 등록카드 사진으로 자동 입력** — 새친구 등록·아이 정보 수정 창 맨 위의 `📷 등록카드 사진으로 자동 입력`을 누르면 카메라(또는 앨범)로 종이 등록카드를 찍어 **이름·생년월일·보호자 연락처·첫 방문일·메모(알레르기 등)**를 입력칸에 자동으로 채웁니다. 사진은 브라우저에서 긴 변 1280px JPEG로 줄여 Supabase Edge Function `scan-registration`(Gemini 비전)으로 보내고, 돌아온 값을 채운 뒤 **저장은 담당자가 확인하고 누릅니다.** 키가 없거나 AI가 붐비면 "잠시 뒤 다시" 안내가 뜨고 직접 입력하면 됩니다.
- **v1.4 🎓 졸업 예정자 카드 강조** — 졸업까지 1년 이내(D-365~D-0)인 아이는 카드에 **따뜻한 앰버 테두리·배경**과 `🎓 졸업 예정` 배지, 직접 지정한 졸업일이 이미 지난 아이는 `🎓 지난 졸업` 배지(v1.8에서 표기 변경)로 한눈에 구분됩니다. 1년 넘게 남은 아이는 기존처럼 일반 카드 + `🎓 D-xxx`만 표시합니다.

## 공유 저장 구조 (Supabase)

- 프로젝트: `lfgc-toddler-attendance` (조직 `LFGC`, Free $0 플랜, 리전 `eu-west-2` West Europe — London)
- Project URL: `https://vyvgkmjekenwgjklrsxq.supabase.co`
- 테이블 `public.app_state` — 앱 자료를 key 단위 문서로 나눠 저장합니다.
  | key | 내용 |
  | --- | --- |
  | `meta` | 관리자 계정·관리자 PIN·앱 설정(`settings`: 제목·공지·졸업 기준 월/나이) |
  | `classes` | 반 목록(이름·소개·PIN·새 반의 색/이모지, **배열 순서 = 화면 순서**) |
  | `teachers` | 담당 선생님 명단(생일은 `birthday`에 `"03-14"`처럼 **월-일만** 저장, 없으면 필드 없음) |
  | `children` | 원아 명단(생일·첫 방문일·유의사항·사진) |
  | `att:YYYY-MM-DD` | 그 주일(일요일) 출석 기록 |
  | `prayer:YYYY-MM-DD` | 그 주 기도제목과 '함께 기도했어요' |
- 열: `key`(PK) · `data`(jsonb) · `rev`(bigint, 밀리초 시각) · `updated_by`(기기 id) · `updated_at`
- RLS: `anon`·`authenticated` 역할에 select/insert/update/delete 허용 (앱이 회원가입 없이 반별 1탭 입장이라 anon 키로 씁니다)
- 실시간: 같은 채널(`lfgc-attendance-sync`)로 바뀐 key만 방송(broadcast)하고, 받은 기기는 그 key만 다시 읽습니다. `app_state`는 `supabase_realtime` 발행에도 들어 있어 Postgres 변경 알림도 함께 받습니다. 30초마다·화면 복귀 시·온라인 복귀 시 한 번씩 확인합니다.
- 충돌: 같은 주일 출석이 두 기기에서 겹치면 아이별로 더 늦게 찍은 기록(`at`)을 남기고, 기도 '함께 기도했어요'는 합칩니다.
- 접속 정보는 `repos/lfgc-nursery-attendance/.env.local`(git 제외)에 있습니다. **DB 비밀번호와 service_role 키는 절대 이 저장소(index.html 포함)에 올리지 않습니다.**

## 등록카드 사진 자동 입력 (v1.4)

- Edge Function: `scan-registration` (프로젝트 `vyvgkmjekenwgjklrsxq`, `verify_jwt=false`, CORS `*`)
  - 앱은 `POST {SUPABASE_URL}/functions/v1/scan-registration` 에 `{ imageBase64, mimeType }` 를 보냅니다(헤더 `apikey`·`Authorization: Bearer <publishable key>`).
  - 응답: `{ ok: true, data: { name, birthDate, parentName, parentPhone, firstVisitDate, notes }, model }` · 실패 시 `{ ok: false, error }`.
  - Gemini 키는 **Edge Function Secrets `GEMINI_API_KEY`** 에만 있습니다. `index.html`·README·커밋에는 절대 넣지 않습니다.
  - 모델: 빠른 `gemini-3.1-flash-lite` 로 먼저 읽고, 거의 못 읽었을 때만 `gemini-3.8-flash` 계열로 한 번 더 시도합니다(붐빌 때 대비).
- 배포·테스트 도구는 `supabase/`(git 제외)에 있습니다: `python3 supabase/deploy_edge_function.py`, `python3 supabase/test_scan.py samples/card_photo.jpg`.

## 배포 방식

- GitHub Pages가 `gh-pages` 브랜치의 루트(`/`)를 서빙합니다. `main`과 `gh-pages`는 같은 내용입니다.
